# GF Restaurant App

A web app that helps people with celiac disease and gluten sensitivities find safe restaurants, save favorites, post reviews, and discuss on a forum.

## Monorepo layout

```
gf-restaurant-app/
├── frontend/            # Next.js app (App Router, JavaScript, Tailwind CSS)
├── backend/             # Backend API (TBD)
├── PROJECT_OVERVIEW.md  # Detailed project reference (tech stack, data models, API, etc.)
└── README.md            # This file
```

## Getting started

### Frontend

```bash
cd frontend
npm install
npm run dev
```

Then open [http://localhost:3000](http://localhost:3000).
